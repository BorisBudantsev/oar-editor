## [2.2.1] — 2026-10-07

### Исправлено

- **Закрытие окна с выбором «Не сохранять» больше не восстанавливает отвергнутые изменения.**
  Раньше при закрытии окна вызывался форсированный сброс автосейва (`_flush_autosave`) **до**
  диалога Save/Discard/Cancel. Если пользователь выбирал «Не сохранять», автосейв всё равно
  содержал изменения, и при следующем запуске предлагалось их восстановить. Теперь при выборе
  «Не сохранять» автосейв **очищается** (`AutosaveModel.clear()`).
- Удалён метод `_flush_autosave` — он больше не нужен: при «Сохранить» автосейв очищается
  внутри `save_project()`, при «Отмене» окно не закрывается, при «Не сохранять» —
  сбрасывается явно.

Здесь описываются изменения, которые уже внесены в код, но ещё не вошли в релиз.

## [2.2.0] — 2026-10-06

### Добавлено

- **Дежурство на дому.** Через контекстное меню ячейки сотрудника (правый клик)
  можно поставить или снять флаг дежурства на дому. Отмечается **цветом фона**
  ячейки, значение при этом остаётся чистым — `З`, `*`, `Д` и т. д.

### Цвета ячеек

| Ситуация | Цвет |
|----------|------|
| Будни, без Д | белый `#FFFFFF` |
| Будни, с Д | средний серый `#CCCCCC` |
| Выходной, без Д | средний серый `#CCCCCC` |
| Выходной, с Д | тёмно-серый `#969696` |
| Ошибка валидации, без Д | светло-розовый `#FFB4B4` |
| Ошибка валидации, с Д | тёмно-красный `#C06060` |

Все тона различимы при чёрно-белой печати.

### Правила

- Флаг доступен **всем сотрудникам**: врачам и медицинским сёстрам, постоянным
  и совместителям.
- **В служебные ячейки** (`Э`, `О`, строка примечаний) флаг не ставится.
- **Не копируется** через «Копировать/Вставить» — это отдельное свойство ячейки,
  не значение.
- **Не участвует в валидации** — не влияет на «Э + О + 1», подсчёт дежурных
  и прочие проверки.
- **Не учитывается в аналитике** загруженности.
- **Не влияет на выпадающий список** значений ячейки (ЛКМ-редактор работает
  с базовым значением, флаг сохраняется).
- Отменяется через `Ctrl+Z` (через отдельную команду `DutyHomeCommand`).

### Экспорт

- Заливка ячеек по флагу `duty_home` добавлена в HTML, Excel, Word и PDF.
  Цвета те же, что в интерфейсе.

### Изменено

- Версия формата JSON повышена с `2.1` до `2.2` (добавлено поле `duty_home`
  у каждого сотрудника — массив `bool` длиной, равной числу дней месяца).
- Файлы версии `2.1` открываются без изменений: массив `duty_home`
  автоматически инициализируется `False`.

### Удалено

- **«Очистить ячейку»** из контекстного меню (ПКМ по ячейке). Очистка значения
  теперь только через ЛКМ → выпадающий список → «очистить». Флаг Д не затрагивается.
- **«Очистить день»** из контекстного меню (ПКМ по заголовку столбца).
  Массовая очистка дня убрана — каждая ячейка очищается отдельно.
- Методы `_ctx_clear_cell`, `_on_header_context_menu`, `clear_days`.

### Технические детали

- 10 новых автотестов для `get_duty_home_at` / `set_duty_home_at`
  в `tests/test_duty_home.py`.
- Всего в проекте **72 теста**.

Здесь описываются изменения, которые уже внесены в код, но ещё не вошли в релиз.

## [2.1.0] — 2026-10-03

### Добавлено

- **Строка примечаний.** После служебных строк `Э` и `О` в графике появилась
  третья строка — свободные примечания по дням. Ограничение текста — 10 символов.
  Примечания экспортируются вместе с графиком во все форматы. В валидации
  не участвуют, в аналитике не учитываются.
- В экспортных файлах (HTML, Excel, Word, PDF) заголовки столбцов теперь
  показывают день недели под числом — так же, как в главном окне приложения.

### Изменено

- Версия формата JSON повышена с `2.0` до `2.1` (добавлено поле `notes`).
  Файлы версии `2.0` открываются без изменений — массив примечаний
  автоматически заполняется пустыми строками.
- Константа `WEEKDAY_SHORT` вынесена в `utils/constants.py` — используется
  и в интерфейсе, и в экспорте (раньше была локально в контроллере).

### Технические детали

- Добавлено 4 автотеста: roundtrip примечаний в `ProjectModel`, загрузка
  с/без поля `notes`, проверка длины массива. Всего в проекте **58 тестов**.

## [2.0.0] — 2026-09-29

Проект разделён на **две независимые сборки** — для врачей и для медицинских сестёр.
Из одного исходного кода собираются два разных приложения: `OAR_Doctors.exe` и `OAR_Nurses.exe`.

### Добавлено

- **Приложение для медицинских сестёр** (`OAR_Nurses.exe`). Полностью аналогично
  приложению врачей по функциональности, но с собственным справочником, собственным
  стилем интерфейса (терминология, иконка, заголовки) и отдельной папкой данных.
- Роль приложения определяется автоматически по имени exe. При запуске из исходников
  роль задаётся аргументом: `python main.py --role nurse`.
- Файл `app_config.py` — единая конфигурация, зависящая от роли: название приложения,
  имя папки данных, тексты интерфейса, имена экспортируемых файлов, иконка.
- JSON-проект теперь содержит поле `role` (`doctor` / `nurse`). Приложение врачей
  открывает только врачебные проекты, приложение медсестёр — только сестринские.
- В диалоге сохранения имя файла включает роль: `График_врачей_Сентябрь_2026.json`
  и `График_медсестёр_Сентябрь_2026.json`.

### Изменено

- **Путь к базе данных** в собранном exe изменён: раньше был
  `%APPDATA%\OAR_Editor\app_data.db`, теперь — `%APPDATA%\OAR_Doctors\app_data.db`
  для врачей и `%APPDATA%\OAR_Nurses\app_data.db` для медсестёр.
- Версия формата JSON повышена с `1.0` до `2.0`. Старые файлы без поля `role`
  (версия 1.0) считаются врачебными — обратная совместимость сохранена.
- Заголовок окна, шапка, тексты меню, кнопок и диалогов зависят от роли.
- Названия экспортируемых файлов включают роль: `График_врачей_…` / `График_медсестёр_…`.

### Технические детали

- Один репозиторий, один исходный код, две сборки.
- Два spec-файла: `OAR_Doctors.spec` и `OAR_Nurses.spec`.
- Иконки: `assets/app_doctors.ico` (синяя, крест) и `assets/app_nurses.ico`
  (бирюзовая, сердце с крестом).
- 59 автотестов (было 51, добавлены: 3 на роль в JSON, 5 на миграцию).
- Общая логика графиков (валидация, аналитика, экспорт) не менялась — правила
  для медсестёр идентичны правилам для врачей.

Здесь описываются изменения, которые уже внесены в код, но ещё не вошли в релиз.

## [1.1.4] — 2026-09-19

### Исправлено

- При закрытии окна автосохранение действительно сбрасывается: раньше в `closeEvent`
  вызывалась ссылка на метод (`self._flush_autosave`) вместо вызова (`self._flush_autosave()`),
  из-за чего отложенные изменения могли потеряться, если пользователь закрывал окно
  до срабатывания debounce-таймера.
- Команда «Очистить день» (по правому клику на заголовке столбца) запускает автосохранение
  через общий callback изменения модели. Раньше автосохранение после очистки дня не срабатывало.
- Эндоскопия ограничена 3 местами (`ЭНД1`, `ЭНД2`, `ЭНД3`). Раньше в служебной строке `Э`
  допускалось значение `4`, но заполнить четвёртое место было невозможно — код `ЭНД4`
  отсутствует. Теперь для строки `Э` допустимы значения 1–3, для `О` — 1–4.
- Для совместителя с рабочим кодом команда «Очистить день» возвращает `*`, а не пустую
  ячейку — так же, как «очистить» в выпадающем списке и «Очистить ячейку» в контекстном меню.

### Добавлено

- Два теста для проверки границ эндоскопии и операционной (`test_endo_four_is_invalid`,
  `test_oper_four_is_valid`). Всего 36 тестов.

## [1.1.0] — 2026-09-17

### Добавлено
- Справочник сотрудников как отдельное окно: пункт меню «Инструменты → Справочник сотрудников».
  Позволяет добавлять, редактировать и удалять сотрудников без создания нового проекта.
- Редактирование сотрудников кнопкой «✎» в строке списка — работает и в мастере создания
  проекта, и в отдельном справочнике.
- Валидация вставки из буфера обмена: значение проверяется на допустимость для конкретной
  ячейки. Недопустимые значения отклоняются с сообщением в статусной строке.
- Автоматические тесты (pytest) для моделей, валидации и аналитики — 25 тестов в папке `tests/`.

### Изменено

- База данных в собранном .exe хранится в `%APPDATA%\OAR_Editor\app_data.db`.
  Раньше создавалась рядом с exe и могла теряться после закрытия onefile-сборки
  или при запуске из папки без прав на запись.
- Автосохранение срабатывает с задержкой 1,5 с после последнего изменения (debounce).
  Снижает нагрузку при заполнении графика — раньше запись в SQLite происходила
  на каждое изменение ячейки.
- UPX-упаковка отключена — меньше ложных срабатываний антивирусов.
- При старте без проекта шапка показывает «График не создан», столбцы не подсвечиваются
  красным, валидация не запускается. Раньше отображался фейковый «Январь 2025».
- В `.spec` больше не вшивается `data/app_data.db` — в exe попадает только иконка.

### Исправлено

- Автосохранение не теряется при создании нового проекта: раньше после Ctrl+N → «Создать»
  автосейв сразу очищался, и при закрытии окна без правок проект исчезал.
- Удалены демонстрационные сотрудники (Иванов, Петров, Сидорова, Кузнецов) — они
  появлялись при первом запуске до создания проекта.


## [1.0.0] — 2026-09-16

Первая рабочая версия. Приложение готово к использованию в отделении.

### Добавлено

- Мастер создания проекта: выбор месяца, года, состава сотрудников из справочника.
- Справочник сотрудников в SQLite: постоянные и совместители, добавление, удаление, редактирование, поддержка дубликатов имён.
- Таблица графика с группировкой: постоянные сверху, совместители снизу, жирная линия-разделитель между группами.
- Заливка суббот и воскресений светло-серым, дни недели в заголовке столбцов.
- Выпадающий список допустимых кодов при редактировании ячейки; правила для совместителей: рабочее место ставится только после символа `*`.
- Команда «очистить» в выпадающем списке с разной логикой для постоянных и совместителей.
- Служебные строки `Э` и `О` — количество мест в эндоскопии и операционной.
- Автоматическая валидация графика: подсветка проблемных столбцов красным, всплывающие подсказки с описанием ошибок.
- Диалог «Список ошибок» с полным перечнем найденных нарушений.
- Анализ загруженности в трёх вкладках: по сотрудникам, по рабочим местам, общий итог.
- Экспорт графика в HTML, Excel, Word, PDF.
- Экспорт отчёта анализа загруженности в HTML, Excel, Word, PDF.
- Сохранение и загрузка проектов в JSON с полной валидацией структуры и версии.
- Автосохранение в SQLite с восстановлением после сбоя или случайного закрытия.
- Отмена и повтор изменений ячеек (Ctrl+Z / Ctrl+Y).
- Контекстное меню ячейки: копировать, вставить, очистить.
- Выделение одного дня или диапазона дней кликом по заголовку столбца; очистка выделенных дней через контекстное меню.
- Вопрос о сохранении при закрытии окна с несохранёнными изменениями.
- Иконка приложения.
- Сборка в один `.exe` через PyInstaller.
- README с описанием функций и инструкцией пользователя.

### Изменено

- Вместо выбора месяца и года в шапке главного окна — только отображение текущего месяца и года. Смена возможна только через создание нового проекта.
- Меню «Правка» сокращено до «Отменить» и «Повторить». Остальные действия перенесены в контекстные меню.
- Функция очистки дней перенесена из отдельного диалога в контекстное меню заголовка столбца.

### Удалено

- Пункт меню «Очистить всё».
- Команды добавления и удаления сотрудников из меню «Правка» (заменены на работу через мастер).
- Кнопка PDF из панели инструментов (экспорт доступен через меню «Экспорт»).

### Известные ограничения

- Состав сотрудников и их категории можно менять только через мастер при создании нового проекта.
- Undo/redo работает только с изменениями ячеек. Удаление сотрудника, смена категории, очистка дня не откатываются.
- Столбцы нельзя скрывать или сворачивать.
- Нет drag-and-drop между ячейками и диапазонного копирования.
- Нет печати на принтере напрямую — только экспорт в PDF.
