# Правила работы с графиком ОАР

Документ описывает правила предметной области, заложенные в приложение
«Редактор графика ОАР». Нужен разработчикам и администраторам, чтобы
понимать логику валидации, ограничения интерфейса и структуру данных.

## Участники

В графике участвуют сотрудники двух категорий.

- **Постоянные** — штатные сотрудники отделения. Работают в операционной,
  эндоскопии, дежурят, имеют выходные и резервные дни.
- **Совместители** — приходящие сотрудники. Отмечают свою доступность
  символом `*`, а в дни, когда они нужны, занимают рабочее место.

Состав сотрудников задаётся в справочнике и фиксируется при создании
проекта через мастер. После создания проекта состав и категории
сотрудников изменить нельзя — можно только создать новый проект.

## Роли и места в течение дня

В течение рабочего дня в отделении есть несколько типов мест.

### Операционная

Четыре кода: `З`, `Б`, `Ж`, `К`. Каждый код — одно рабочее место. Всего
в операционной может работать от 0 до 4 человек одновременно. Точное
число мест на конкретный день задаётся в служебной строке `О` (значение
от 1 до 4).

### Эндоскопия

Три кода: `ЭНД1`, `ЭНД2`, `ЭНД3`. Каждый — одно рабочее место. Всего
в эндоскопии может работать от 0 до 3 человек. Точное число мест на конкретный день задаётся в служебной строке Э (значение от 1 до 3 — в отделении три эндоскопических места, коды ЭНД1, ЭНД2, ЭНД3).

### Дежурный

Код `Д`. В каждом дне должен быть **ровно один** дежурный. Дежурный
не занимает место в операционной или эндоскопии.

### Резерв (только для постоянных)

Коды `до 16` и `до 17` — сотрудник в резерве до указанного времени.
Не считается работающим на конкретном месте. Используется для планирования.

### Выходной (только для постоянных)

Код `вых`. Сотрудник в этот день не работает.

### Доступность (только для совместителей)

Код `*`. Совместитель сообщил, что в этот день может выйти на работу,
но конкретное место ещё не назначено.

## Правило числа работающих

Для каждого дня число работающих сотрудников должно быть равно сумме
мест в операционной и эндоскопии плюс один дежурный:
Работающих = О + Э + 1

где `О` — количество мест в операционной (служебная строка «О»),
`Э` — количество мест в эндоскопии (служебная строка «Э»),
`1` — дежурный.

Если число работающих не совпадает — это ошибка, день подсвечивается
красным.

**Что считается работающим:** коды `З`, `Б`, `Ж`, `К`, `ЭНД1`, `ЭНД2`,
`ЭНД3`, `Д`.

**Что не считается работающим:** пустая ячейка, `*`, `вых`, `до 16`,
`до 17`.

## Правило одного места

На каждом рабочем месте в один день может стоять **не более одного**
сотрудника. Нельзя поставить двух человек на «З», двух на «ЭНД1» или
двух на «Д». Если это произошло — ошибка.

## Правило одного дежурного

В каждом дне должен быть **ровно один** сотрудник с кодом `Д`.

- Если дежурных ноль — ошибка «Отсутствует дежурный».
- Если дежурных больше одного — ошибка «Дежурных N, должен быть один».

## Правило служебных строк

Служебные строки Э и О должны быть заполнены в каждом дне. Для Э — значения 1–3, для О — 1–4. Пустое значение — ошибка.

Число мест в этих строках определяет, сколько сотрудников должны быть
распределены по операционной и эндоскопии в этот день.

## Правила для совместителей

Совместитель отличается от постоянного тем, что его участие в графике
проходит в два шага.

**Шаг 1.** Совместитель отмечает свою доступность символом `*`. Это
означает «в этот день я могу выйти».

**Шаг 2.** Если совместитель нужен в конкретном месте, он ставится на
рабочий код (`З`, `Б`, `Ж`, `К`, `ЭНД1`–`ЭНД3`, `Д`). С этого момента
он считается работающим и учитывается в числе работающих.

**Ключевое правило интерфейса:** рабочее место можно поставить совместителю
только в те дни, где уже стоит `*`. Если ячейка пуста, сначала нужно
поставить `*`, и только потом — рабочее место. Если попытаться поставить
рабочее место в пустую ячейку — приложение не позволит.

**Команда «очистить» для совместителя работает так:**

- в ячейке стоит рабочий код (`З`, `Б`, `Ж`, `К`, `ЭНД1`–`ЭНД3`, `Д`) —
  при очистке возвращается `*` (сотрудник снова «доступен», но без места);
- в ячейке стоит `*` — при очистке возвращается пустая ячейка
  (сотрудник больше не доступен в этот день);
- в ячейке пусто — при очистке ничего не меняется.

## Правила для постоянных сотрудников

Постоянный сотрудник в каждый день месяца имеет одно из значений:

| Код | Что означает |
|-----|--------------|
| `""` | пустая ячейка (не назначено) |
| `З`, `Б`, `Ж`, `К` | операционная |
| `ЭНД1`, `ЭНД2`, `ЭНД3` | эндоскопия |
| `Д` | дежурный |
| `вых` | выходной |
| `до 16`, `до 17` | резерв до указанного времени |

У постоянного **не бывает** `*` — это код только для совместителей.

**Команда «очистить» для постоянного** всегда возвращает пустую ячейку.

## Что происходит при смене категории

Категория сотрудника задаётся в справочнике. В рамках одного проекта
её изменить нельзя. Но при создании нового проекта категория берётся
из справочника — то есть если категория сотрудника изменилась в
справочнике, в новых проектах он появится уже в новой категории.

Это осознанное решение: категория — свойство человека, а не графика.

## Валидация графика

Приложение проверяет график автоматически после каждого изменения.
Для каждого дня проверяются следующие правила:

1. Служебные строки `Э` и `О` заполнены; для Э значения 1-3, для О - 1-4.
2. Число работающих совпадает с `Э + О + 1`.
3. Есть ровно один дежурный.
4. На каждом рабочем месте стоит не более одного сотрудника.
5. Заполнено не больше операционных мест, чем указано в `О`.
6. Заполнено не больше эндоскопических мест, чем указано в `Э`.
7. Все значения ячеек допустимы для своей категории.

Если хотя бы одно правило нарушено, столбец дня подсвечивается красным,
а при наведении мыши появляется список ошибок. Полный список ошибок
доступен через **Инструменты → Список ошибок**.

## Что не проверяется

Некоторые ограничения не заложены в валидацию и остаются на усмотрение
составителя графика.

- **Не проверяется отдых после дежурства.** Сотрудник может дежурить
  несколько дней подряд.
- **Не проверяется количество смен в месяц** на одного сотрудника.
- **Не проверяется наличие сотрудника в двух местах в один день.** Это
  невозможно по формату ячейки — в одной ячейке только одно значение.
- **Не проверяется совпадение с пожеланиями сотрудников.** Пожелания,
  если они есть, учитываются вручную при составлении.

## Терминология

- **ОАР** — отделение анестезиологии и реанимации.
- **Э** — эндоскопия, служебная строка с числом мест.
- **О** — операционная, служебная строка с числом мест.
- **ЭНД** — код места в эндоскопии (`ЭНД1`, `ЭНД2`, `ЭНД3`).
- **З, Б, Ж, К** — коды мест в операционной.
- **Д** — дежурство.
- **Вых** — выходной.
- **`*`** — доступность (для совместителей).

## Пример корректного дня

Пусть `Э = 3`, `О = 3`. Тогда в день должно быть 7 работающих.

| Сотрудник | Код | Что делает |
|-----------|-----|------------|
| Иванов | `З` | операционная, место З |
| Петров | `Б` | операционная, место Б |
| Сидоров | `Ж` | операционная, место Ж |
| Смирнова | `ЭНД1` | эндоскопия |
| Кузнецов | `ЭНД2` | эндоскопия |
| Морозова | `ЭНД3` | эндоскопия |
| Галев | `Д` | дежурный |

Остальные сотрудники — с `вых`, `до 16`, `до 17`, `*` или пустыми
ячейками. Все правила соблюдены.

Если, например, Морозова уйдёт в выходной, работающих станет 6 —
это ошибка «Работающих 6, ожидалось 7». Столбец станет красным.
