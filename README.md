# Редактор графиков дежурств ОАР

Два настольных приложения для составления и редактирования графиков работы
отделения анестезиологии и реанимации. Работают локально на Windows, не требуют
интернета и серверной части. Все данные хранятся на компьютере пользователя.

## Два приложения

| Приложение | Для кого | Файл |
|------------|----------|------|
| **OAR_Doctors** | График дежурств врачей | `OAR_Doctors.exe` |
| **OAR_Nurses** | График дежурств медицинских сестёр | `OAR_Nurses.exe` |

Оба приложения **полностью независимы**. Они могут быть установлены на одном
компьютере одновременно или на разных. Ведение графиков врачей и медсестёр
обычно осуществляется разными людьми, часто на разных компьютерах.

Функциональность идентична: те же правила, те же коды, те же форматы экспорта.
Отличия — только в названии, иконке, справочнике и папке с данными.

## Возможности

- Создание проектов графика на любой месяц и год через пошаговый мастер.
- Ведение справочника сотрудников: постоянные и совместители.
- Редактирование назначений по дням месяца через выпадающие списки.
- Автоматическая валидация: подсветка дней с ошибками и всплывающие подсказки.
- Отмена и повтор действий (Ctrl+Z / Ctrl+Y).
- Автосохранение состояния: восстановление после сбоя или случайного закрытия.
- Сохранение и загрузка проектов в файлы JSON.
- Анализ загруженности: отчёт по сотрудникам, по рабочим местам и общий итог.
- Экспорт графика и отчётов в HTML, Excel, Word и PDF.
- Строка примечаний под служебными строками `Э` и `О` — свободный текст по дням.
- Отметка дежурства на дому — цветом фона ячейки.

## Установка

### Способ 1. Готовый `.exe`

Скачайте нужный файл из раздела
[**Releases**](https://github.com/BorisBudantsev/oar-editor/releases):

- `OAR_Doctors.exe` — для графика врачей
- `OAR_Nurses.exe` — для графика медицинских сестёр

Скопируйте файл на свой компьютер и запустите двойным щелчком. Никаких
дополнительных программ устанавливать не нужно.

При первом запуске рядом с системной папкой пользователя создастся база данных:

- для врачей — `%APPDATA%\OAR_Doctors\app_data.db`
- для медсестёр — `%APPDATA%\OAR_Nurses\app_data.db`

### Способ 2. Запуск из исходников

Этот способ нужен, если вы хотите запустить приложение из кода или что-то доработать.
Требуется Python 3.10 или новее с сайта python.org. При установке Python обязательно
поставьте галочку «Add Python to PATH».

Откройте терминал в папке проекта и выполните по очереди:
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

Приложение для врачей
python main.py

Приложение для медсестёр
python main.py --role nurse

## Использование

### Создание проекта

Откройте меню **Файл → Новый проект** (или нажмите Ctrl+N). В мастере:

1. Выберите месяц и год.
2. Отметьте галочками сотрудников, которые должны попасть в график.
   Кнопка «Добавить …» позволяет пополнить справочник на месте.
3. Нажмите «Создать».

После этого в таблице появятся выбранные сотрудники, разделённые на две группы:
сверху постоянные, снизу совместители. Между группами — жирная линия. Субботы
и воскресенья залиты светло-серым.

### Редактирование графика

- **Левый клик по ячейке дня** открывает выпадающий список с допустимыми значениями.
- **Правый клик по ячейке** — контекстное меню: «Копировать», «Вставить», «Очистить ячейку».
- **Левый клик по заголовку столбца** выделяет один день.
- **Ctrl + левый клик** по другому заголовку выделяет диапазон дней.
- **Правый клик по заголовку столбца** — «Очистить день» (или «Очистить выделенные дни»).
- **Строка примечаний.** После строк `Э` и `О` находится строка для свободных
  примечаний. Кликните по ячейке и введите текст до 10 символов (например,
  «отпуск», «учёба»). Примечания сохраняются в проекте и попадают в экспорт.
- **Дежурство на дому.** Правый клик по ячейке сотрудника → «Дежурство на дому»
  отмечает ячейку цветом (средний серый в будни, тёмно-серый в выходные).
  Команда «Убрать дежурство на дому» снимает отметку. Значение ячейки
  при этом не меняется. Доступно всем сотрудникам, не копируется
  через буфер, не участвует в валидации и аналитике.

### Коды назначений

Для **постоянных** сотрудников доступны коды: `З`, `Б`, `Ж`, `К` (операционная);
`ЭНД1`, `ЭНД2`, `ЭНД3` (эндоскопия); `Д` (дежурный); `вых` (выходной);
`до 17`, `до 16` (резерв); «очистить» (пустая ячейка).

Для **совместителей** доступны коды: `*` (доступность — сотрудник готов к работе);
`З`, `Б`, `Ж`, `К`; `ЭНД1`, `ЭНД2`, `ЭНД3`; `Д`; «очистить».

**Важное правило:** у совместителя рабочее место можно поставить только из ячейки
со звёздочкой. Если ячейка пустая, сначала поставьте `*`, затем выбирайте рабочее
место. Команда «очистить» в ячейке с рабочим кодом возвращает её к состоянию `*`,
а команда «очистить» в ячейке со `*` полностью очищает ячейку.

### Служебные строки

Внизу таблицы — две служебные строки:

- **Э** — количество мест в эндоскопии в этот день (от 1 до 3).
- **О** — количество мест в операционной в этот день (от 1 до 4).

По этим числам приложение проверяет, что график заполнен корректно: работающих
должно быть ровно `Э + О + 1` (одно место закреплено за дежурным).

### Валидация

Приложение проверяет график автоматически после каждого изменения. Если в столбце
есть ошибки, он подсвечивается красным. Наведите мышь на любой столбец — появится
всплывающая подсказка со списком ошибок. Полный список ошибок можно посмотреть
через меню **Инструменты → Список ошибок**.

Типичные ошибки: число работающих не совпадает с суммой мест; нет дежурного или
их больше одного; на одном месте стоит больше одного сотрудника; не заполнены
служебные строки Э или О; в ячейке стоит недопустимое значение.

### Анализ загруженности

Меню **Инструменты → Анализ загруженности** открывает окно с тремя вкладками.

Вкладка «По сотрудникам» показывает для каждого: количество рабочих дней,
выходных, дежурств, дней в эндоскопии, дней в операционной, отношение операционной
к эндоскопии. Для совместителей дополнительно показывается коэффициент занятости.

Вкладка «По рабочим местам» ранжирует сотрудников по каждому типу мест.

Вкладка «Общий итог» показывает суммарные показатели.

Отчёт можно экспортировать в HTML, Excel, Word или PDF кнопками внизу окна.

### Сохранение и экспорт

- **Файл → Сохранить** (Ctrl+S) — сохранить проект в JSON-файл.
- **Файл → Сохранить как** (Ctrl+Shift+S) — сохранить под другим именем.
- **Файл → Открыть** (Ctrl+O) — открыть ранее сохранённый проект.
- **Меню Экспорт** — выгрузка графика в HTML, Excel, Word или PDF.
  Размер шрифта выбирается в шапке окна (от 6 до 10 pt).

**Файлы проектов привязаны к роли.** JSON врачей открывается только в `OAR_Doctors.exe`,
JSON медсестёр — только в `OAR_Nurses.exe`. При попытке открыть чужой файл приложение
сообщит об ошибке.

### Автосохранение

При каждом изменении графика состояние записывается в локальную базу данных.
Если вы закроете приложение без сохранения, при следующем запуске появится
предложение восстановить последнее состояние. После явного сохранения проекта
автосохранение сбрасывается.

## Горячие клавиши

`Ctrl+N` — новый проект. `Ctrl+O` — открыть. `Ctrl+S` — сохранить.
`Ctrl+Shift+S` — сохранить как. `Ctrl+Z` — отменить. `Ctrl+Y` — повторить.
`Ctrl+Q` — выход.

## Файлы данных

Проекты сохраняются в произвольные JSON-файлы, местоположение выбирает пользователь.

Справочник сотрудников и автосохранение хранятся в SQLite-базе:

- для врачей — `%APPDATA%\OAR_Doctors\app_data.db`
- для медсестёр — `%APPDATA%\OAR_Nurses\app_data.db`

При запуске из исходников база создаётся в папке `data/` рядом с кодом
(`app_data.db` для врачей, `app_data_nurse.db` для медсестёр).

## Системные требования

Windows 10 или Windows 11. При запуске готового `.exe` Python не требуется.
Свободного места — около 100 МБ. Приложение работает без интернета.

## Сборка из исходников

Установите PyInstaller:
pip install pyinstaller

Соберите нужное приложение:
pyinstaller --noconfirm OAR_Doctors.spec → dist\OAR_Doctors.exe
pyinstaller --noconfirm OAR_Nurses.spec → dist\OAR_Nurses.exe
