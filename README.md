# Редактор графика ОАР

Десктопное приложение для составления и редактирования графика работы отделения анестезиологии и реанимации. Работает локально на Windows, не требует интернета и серверной части. Все данные хранятся на компьютере пользователя.

## Возможности

- Создание проектов графика на любой месяц и год через пошаговый мастер.
- Ведение справочника сотрудников: постоянные и совместители.
- Редактирование назначений по дням месяца через выпадающие списки.
- Автоматическая валидация: подсветка дней с ошибками и всплывающие подсказки.
- Отмена и повтор действий (Ctrl+Z / Ctrl+Y).
- Автосохранение состояния: восстановление после сбоя или случайного закрытия.
- Сохранение и загрузка проектов в файлы JSON.
- Анализ загруженности: отчёт по сотрудникам, по рабочим местам и общий итог.
- Экспорт графика и отчётов в HTML, Excel, Word и PDF.

## Установка

Есть два способа запустить приложение.

### Способ 1. Готовый файл OAR_Editor.exe

Скачайте или скопируйте файл `OAR_Editor.exe` на свой компьютер и запустите двойным щелчком. Никаких дополнительных программ устанавливать не нужно. При первом запуске рядом с файлом создастся папка `data` для базы данных.

### Способ 2. Запуск из исходников

Этот способ нужен, если вы хотите запустить приложение из кода или что-то доработать. Требуется Python 3.10 или новее с сайта python.org. При установке Python обязательно поставьте галочку «Add Python to PATH».

Порядок действий описан в разделе «Команды для терминала» в конце документа.

## Использование

### Создание проекта

Откройте меню **Файл → Новый проект** (или нажмите Ctrl+N). В мастере:

1. Выберите месяц и год.
2. Отметьте галочками сотрудников, которые должны попасть в график. Кнопка «Добавить сотрудника» позволяет пополнить справочник на месте.
3. Нажмите «Создать».

После этого в таблице появятся выбранные сотрудники, разделённые на две группы: сверху постоянные, снизу совместители. Между группами — жирная линия. Субботы и воскресенья залиты светло-серым.

### Редактирование графика

- **Левый клик по ячейке дня** открывает выпадающий список с допустимыми значениями.
- **Двойной клик по ячейке** — то же самое.
- **Правый клик по ячейке** открывает контекстное меню с командами «Копировать», «Вставить», «Очистить ячейку».
- **Левый клик по заголовку столбца** выделяет один день.
- **Ctrl + левый клик по другому заголовку** выделяет диапазон дней.
- **Правый клик по заголовку столбца** открывает меню «Очистить день» (или «Очистить выделенные дни», если выделен диапазон).

### Коды назначений

Для постоянных сотрудников доступны коды: `З`, `Б`, `Ж`, `К` — операционная; `ЭНД1`, `ЭНД2`, `ЭНД3` — эндоскопия; `Д` — дежурный; `вых` — выходной; `до 17` и `до 16` — резерв; `очистить` — пустая ячейка.

Для совместителей доступны коды: `*` — доступность (сотрудник готов к работе); `З`, `Б`, `Ж`, `К` — операционная; `ЭНД1`, `ЭНД2`, `ЭНД3` — эндоскопия; `Д` — дежурный; `очистить` — пустая ячейка.

Важное правило: у совместителя рабочее место можно поставить только из ячейки со звёздочкой. Если ячейка пустая, сначала поставьте `*`, затем выбирайте рабочее место. Команда «очистить» в ячейке с рабочим местом возвращает её к состоянию `*`, а команда «очистить» в ячейке со `*` полностью очищает ячейку.

### Служебные строки

Внизу таблицы находятся две служебные строки:

- **Э** — количество мест в эндоскопии в этот день (от 1 до 4).
- **О** — количество мест в операционной в этот день (от 1 до 4).

По этим числам приложение проверяет, что график заполнен корректно: работающих должно быть ровно `Э + О + 1` (одно место закреплено за дежурным).

### Валидация

Приложение проверяет график автоматически после каждого изменения. Если в столбце есть ошибки, он подсвечивается красным. Наведите мышь на любой столбец — появится всплывающая подсказка со списком ошибок. Полный список ошибок можно посмотреть через меню **Инструменты → Список ошибок**.

Типичные ошибки: число работающих не совпадает с суммой мест; нет дежурного или их больше одного; на одном месте стоит больше одного сотрудника; не заполнены служебные строки Э или О; в ячейке стоит недопустимое значение.

### Анализ загруженности

Меню **Инструменты → Анализ загруженности** открывает окно с тремя вкладками.

Вкладка «По сотрудникам» показывает для каждого сотрудника: количество рабочих дней, количество выходных, количество дежурств, количество дней в эндоскопии, количество дней в операционной, отношение операционной к эндоскопии. Для совместителей дополнительно показывается коэффициент занятости — отношение рабочих дней к сумме рабочих дней и оставшихся звёздочек.

Вкладка «По рабочим местам» ранжирует сотрудников по каждому типу мест: эндоскопия, операционная, дежурства, отношение операционной к эндоскопии, коэффициент занятости.

Вкладка «Общий итог» показывает суммарные показатели по всем сотрудникам: смены в эндоскопии, смены в операционной, смены с кодом Ж.

Отчёт можно экспортировать в HTML, Excel, Word или PDF кнопками внизу окна.

### Сохранение и экспорт

- **Файл → Сохранить** (Ctrl+S) — сохранить проект в JSON-файл.
- **Файл → Сохранить как** (Ctrl+Shift+S) — сохранить под другим именем.
- **Файл → Открыть** (Ctrl+O) — открыть ранее сохранённый проект.
- **Меню Экспорт** — выгрузка графика в HTML, Excel, Word или PDF. Размер шрифта выбирается в шапке окна (от 6 до 10 pt).

### Автосохранение

При каждом изменении графика состояние записывается в локальную базу данных. Если вы закроете приложение без сохранения, при следующем запуске появится предложение восстановить последнее состояние. После явного сохранения проекта автосохранение сбрасывается.

## Горячие клавиши

Ctrl+N — новый проект. Ctrl+O — открыть. Ctrl+S — сохранить. Ctrl+Shift+S — сохранить как. Ctrl+Z — отменить. Ctrl+Y — повторить. Ctrl+Q — выход.

## Файлы данных

Проекты сохраняются в произвольные JSON-файлы, местоположение выбирает пользователь. Справочник сотрудников и автосохранение хранятся в базе данных SQLite, файл `app_data.db`. В режиме разработки он лежит в папке `data/` рядом с кодом. В собранном `.exe` — в папке `%APPDATA%\OAR_Editor\`.

## Системные требования

Windows 10 или Windows 11. При запуске готового `.exe` Python не требуется. Свободного места — около 100 МБ. Приложение работает без интернета.

## Команды для терминала

### Установка зависимостей и запуск из исходников

Откройте терминал в папке проекта и выполните по очереди:
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py

Первая команда создаёт виртуальное окружение. Вторая — активирует его в текущем терминале (в приглашении появится `(venv)`). Третья — устанавливает библиотеки. Четвёртая — запускает приложение.

### Обновление зависимостей

Если вы добавили новую библиотеку в проект, обновите файл `requirements.txt`:
pip freeze > requirements.txt

### Сборка в .exe

Установите PyInstaller:
pip install pyinstaller

Соберите приложение по spec-файлу:
pyinstaller --noconfirm OAR_Editor.spec

Готовый файл появится в папке `dist/OAR_Editor.exe`.

## Структура проекта

Папка `models` содержит модель данных графика, модель справочника сотрудников и модель автосохранения. Папка `views` — главное окно, диалоги, делегаты таблицы и диалоги валидации и статистики. Папка `controllers` — контроллер проекта, экспорт и команды отмены. Папка `utils` — работа с JSON, база данных, константы, валидация, аналитика. Папка `assets` — иконка приложения. Папка `data` — база данных SQLite в режиме разработки.
