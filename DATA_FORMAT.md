# Формат данных

Описание форматов хранения приложения «Редактор графика ОАР».

## Где что хранится

| Что | Формат | Где |
|-----|--------|-----|
| Проекты графика | JSON | произвольные `.json`-файлы |
| Справочник сотрудников | SQLite | `app_data.db`, таблица `employees` |
| Настройки | SQLite | `app_data.db`, таблица `settings` |
| Автосохранение | SQLite | `app_data.db`, таблица `autosave` |

В режиме разработки `app_data.db` лежит в папке `data/`. В собранном `.exe` —
в `%APPDATA%\OAR_Editor\app_data.db`.

## Формат JSON-проекта

Один файл `.json` — один график на конкретный месяц.

### Структура

```json
{
  "version": "1.0",
  "month": 8,
  "year": 2026,
  "employees": [
    {"id": 1, "name": "Иванов И.И.", "category": "permanent",
     "days": ["З", "Б", "вых", "", "Д", ...]},
    {"id": 2, "name": "Петров П.П.", "category": "parttime",
     "days": ["*", "ЭНД1", "", ...]}
  ],
  "special": {"Э": ["3", "3", ...], "О": ["3", "3", ...]},
  "nextId": 3
}
Поля верхнего уровня
Поле	Тип	Описание
version	строка	Версия формата. Текущая — "1.0". При несовпадении файл не откроется.
month	целое	0 (январь) … 11 (декабрь).
year	целое	1900–2200.
employees	массив	Список сотрудников.
special	объект	Служебные строки «Э» и «О».
nextId	целое	Следующий свободный ID.
Сотрудник
Поле	Описание
id	Уникальный внутри проекта. Не связан с ID в SQLite.
name	ФИО.
category	permanent или parttime.
days	Массив строк, длина = числу дней месяца.
Допустимые значения в days:

Для постоянного: "", З, Б, Ж, К, ЭНД1, ЭНД2, ЭНД3, Д, вых, до 17, до 16.
Для совместителя: "", *, З, Б, Ж, К, ЭНД1, ЭНД2, ЭНД3, Д.

Индекс i в массиве соответствует дню i+1 месяца.

Служебные строки special
Два массива строк — Э и О — длина равна числу дней месяца. Значения — "1"–"4" или "". При создании проекта заполняются "3".
Схема SQLite app_data.db
CREATE TABLE employees (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    category TEXT NOT NULL
);

CREATE TABLE settings (
    key TEXT PRIMARY KEY,
    value TEXT
);

CREATE TABLE autosave (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    data_json TEXT NOT NULL,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
);
employees — справочник. Дубликаты имён разрешены, различаются по id.

settings — ключ-значение для будущих настроек.

autosave — последнее состояние проекта. В таблице всегда не более одной строки: при сохранении предыдущие удаляются.
Версионирование
Формат JSON версионируется через поле version. При изменении структуры версия повышается, старые файлы перестают открываться. Механизма миграции пока нет.
